Storytopia 📖✨

Storytopia is an interactive storytelling platform where users can read, listen, create, share, and explore unique stories. The platform allows users to craft their own narratives and store them in a database, making storytelling more engaging and accessible.

🌟 Features

📖 Read stories of any theme in your preferred language
🔊 Listen to stories with text-to-speech support
📝 Create personalized stories with ease
📚 Store and manage stories in the database
🔍 Explore stories from other users
🎨 User-friendly UI/UX for an immersive experience
🛠️ Tech Stack

Frontend: HTML, CSS, JavaScript.
Backend: Node.js, Express.js,hbs.
Database: MongoDB
